**Check** is our test of each ONNX build against the released model in the Cactus engine, on that language's own test sets. The rules ask for a match, so a build can miss one by scoring better as well as worse. PASS means all our rules held. MIXED means the builds matched the engine on the main sets and the named part did not. FAIL means a build missed our test on a main set; each one is listed below. Details: [RESULTS.md](https://huggingface.co/udgamlabs/Shruti-ONNX/blob/main/RESULTS.md); on Linux x86: [RESULTS_LINUX_X86.md](https://huggingface.co/udgamlabs/Shruti-ONNX/blob/main/RESULTS_LINUX_X86.md).

Numbers come out as spoken words. See [limits.md](limits.md).

## Languages that failed our test

9 of the 22 ONNX builds in this release failed: Dogri, Hindi, Kannada, Konkani, Odia, Punjabi, Sindhi, Tamil, Telugu. We publish them with the misses stated here. If a build's misses matter for your use, the language's engine file in the table above is the original.

- **Dogri failed our written test, and we publish it as a marked exception.** The test asks each set to match the original engine within its 95% interval, in either direction. More errors than the engine: `onnx/` DiarBench, own script +1.88 [+0.40, +3.29]; `onnx/` DiarBench, romanised +1.46 [+0.22, +2.83]. Fewer errors than the engine, which also counts as a miss: `onnx-int8/` IndicVoices, romanised -1.17 [-2.73, -0.02]. `sherpa-onnx/` has no such miss.
